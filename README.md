# 🐾 Landing Page - Heloisa Fernandes

## Sobre
Landing page profissional para **Heloisa Fernandes**, Médica Veterinária em Bauru-SP. Site otimizado para conversão, SEO local e experiência mobile.

**Especialidades:** Clínica Geral, Odontologia, Dermatologia e Aplicações para Pequenos Animais

---

## 🎯 Objetivo do MVP
- ✅ Apresentar Heloisa como profissional de confiança
- ✅ Facilitar agendamento via WhatsApp
- ✅ Mostrar especialidades e horários
- ✅ Otimizar para buscas locais ("veterinária Bauru")
- ✅ Mobile-first (60% dos acessos vêm de celular)

---
